# AURA ANIME 🔮

Developer Credit: **Developer: @Safenyorochi**

## Overview
AURA ANIME is a modern Progressive Web App (PWA) with Kurdish Sorani RTL support, brand logo, custom admin passcode `[AURA-ADMIN-2026]`, and zero preset anime so you can populate it entirely from scratch.

## Deployment Instructions
1. **GitHub Pages**: Upload all files to your GitHub repository and enable GitHub Pages.
2. **Railway Backend**: Deploy to Railway and set environment variable `ADMIN_PASSWORD` to `AURA-ADMIN-2026`.
